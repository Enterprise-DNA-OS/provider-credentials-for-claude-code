# Why there is no front end

Credential administrators already work from evidence, dates, register checks and committee decisions. Those records fit a database and a short set of recurring commands. Ask for the renewal queue, review the evidence, then record the actual outcome.

The HTML views show the week and the committee pack. They do not change records. Documents are printable review copies. Claude Code, Codex, OpenCode or Cursor can run the same CLI and explain its results.

A dedicated screen provides quick visual navigation, mobile capture, forms and drag-and-drop uploads. This free build has none of those, and no offline synchronisation or live register polling. A controlled evidence folder and an operator using the CLI are sufficient for its credential-desk workflows.
